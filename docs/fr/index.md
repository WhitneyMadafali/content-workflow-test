# Accueil des analyses de contenu

Ce site explique l'utilisation des outils d'analyse suivants :

- [Analyse SharePoint](tools/sharepoint-scan.md)
- [Analyse Teams](tools/teams-scan.md)
- [MCP Teams](tools/teams-mcp.md)
- [MCP reponses Forms](tools/forms-responses-mcp.md) (lire et resumer les soumissions Microsoft Forms)
- [Liens Forms dans Teams](tools/forms-mcp.md) (exporter les messages de canal contenant des URL Forms)

## Portee rapide

- Pour analyser dossiers/fichiers SharePoint et exporter en JSON : utilisez Analyse SharePoint
- Pour analyser equipes/canaux/messages/reponses/fichiers Teams : utilisez Analyse Teams
- Pour acceder aux canaux/chats Teams via un client MCP : utilisez MCP Teams
- Pour les **donnees de soumission** via l'API Forms : utilisez [MCP reponses Forms](tools/forms-responses-mcp.md)
- Pour **exporter les messages Teams** contenant des liens Microsoft Forms : utilisez [Liens Forms dans Teams](tools/forms-mcp.md)

## Demarrage recommande

1. Lire les etapes d'installation et d'authentification
2. Faire un test sur petite portee (limites basses)
3. Etendre la portee et exporter les JSON finaux
