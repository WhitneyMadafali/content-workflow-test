# 内容扫描文档首页

本网站用于说明如何使用下列扫描与相关工具：

- [SharePoint 扫描](tools/sharepoint-scan.md)
- [Teams 扫描](tools/teams-scan.md)
- [Teams MCP](tools/teams-mcp.md)
- [Forms 答卷 MCP](tools/forms-responses-mcp.md)（读取与总结 Microsoft Forms 提交）
- [Teams 频道中的 Forms 链接](tools/forms-mcp.md)（导出含 Forms URL 的频道帖子）

## 适用场景概览

- 需要扫描 SharePoint 文件夹、文件和导出 JSON：使用 SharePoint 扫描
- 需要扫描 Teams 团队、频道、消息/回复及频道文件：使用 Teams 扫描
- 需要在 MCP 客户端中读取 Teams 频道/聊天：使用 Teams MCP
- 需要读取或总结 **表单提交记录**（Forms API）：使用 [Forms 答卷 MCP](tools/forms-responses-mcp.md)
- 需要在 Teams 频道中 **导出含 Microsoft Forms 链接的帖子**：使用 [Teams 频道中的 Forms 链接](tools/forms-mcp.md)

## 推荐开始步骤

1. 先阅读对应工具页面的安装与认证说明
2. 先做小范围测试（低 limit）
3. 再扩大扫描范围并输出正式 JSON
