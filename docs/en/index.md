# Content Scanning Home

This site explains how to use the two scanning tools:

- [SharePoint Scan](tools/sharepoint-scan.md)
- [Teams Scan](tools/teams-scan.md)
- [Teams MCP](tools/teams-mcp.md)

## Quick Scope

- Need to scan SharePoint folders/files and export JSON: use SharePoint Scan
- Need to scan Teams teams/channels/messages/replies/files: use Teams Scan
- Need Teams channels/chats access from an MCP client: use Teams MCP

## Recommended Start

1. Read install/auth steps on the tool page
2. Run a small-scope test first (low limits)
3. Scale up and export final JSON outputs
