# Content Scanning Home

This site explains how to use the scanning tools below:

- [SharePoint Scan](tools/sharepoint-scan.md)
- [Teams Scan](tools/teams-scan.md)
- [Teams MCP](tools/teams-mcp.md)
- [Forms responses MCP](tools/forms-responses-mcp.md) (read and summarize Microsoft Forms submissions)
- [Forms links in Teams](tools/forms-mcp.md) (export channel posts that contain Forms URLs)

## Quick Scope

- Need to scan SharePoint folders/files and export JSON: use SharePoint Scan
- Need to scan Teams teams/channels/messages/replies/files: use Teams Scan
- Need Teams channels/chats access from an MCP client: use Teams MCP
- Need **form submission data** from the Forms API: use [Forms responses MCP](tools/forms-responses-mcp.md)
- Need to **export Teams posts** that contain Microsoft Forms links: use [Forms links in Teams](tools/forms-mcp.md)

## Recommended Start

1. Read install/auth steps on the tool page
2. Run a small-scope test first (low limits)
3. Scale up and export final JSON outputs
