## Key Concepts

### Content Dimensions
```
Content = {
  information: InformationModel,    // The "what" - facts, data, knowledge
  narration: NarrativeStrategy,     // The "how" - storytelling approach
  media: DeliveryChannel           // The "where" - rendering target
}
```

### Lifecycle Stages
```
Genesis → Seed → Content Model → Rendered Instance → Published Artifact
  ↓         ↓          ↓               ↓                    ↓
Chaos   Structure   Schema      Code Component        Live Delivery
```
